# Carrot Rush
A 2D mobile platformer for iPhone (landscape). A rabbit jumps and shoots
through two levels
and a boss fight to win back the carrots a fox stole.
- Engine: Unity 6000.6.1f1
- Course: Game Development Fundamentals, Narxoz University
- Author: Sabina Mustafina
## How to open
Clone the repository, then in Unity Hub: Add → Add project from disk → select
this folder.
Start from Assets/Scenes/MainMenu.unity.
